## §C CONSTRAINTS

- emit `hk.pklith.pkl` (Mapping<String, Step>, consumer `hk.pkl` imports & merges), `nix/pklith.nix` (`pkgs: [ … ]`), AGENTS.md block between `<!-- BEGIN pklith -->`/`<!-- END pklith -->`.
- header `generated by pkli gen — do not edit`. write only on change.
- per-check emit fn reused by src/lay (1 check → its fragment).
- Rust module is `r#gen`: `gen` is a reserved keyword since edition 2024; the raw identifier keeps node = dir = module (`.:C`).
- shared tool configs (`.markdownlint.yml`, `.yamllint.yml` …) of active fragments copied from embedded templates; gitignored; replaces set-and-setting `sync-setting`.

## §V INVARIANTS

V1: ∀ check used by registry → 1 hk step & 1 nix attr & 1 AGENTS row; unused catalog row ⊥ emitted
V2: idempotent: 2nd run writes ⊥
V3: `--check` exit 1 iff on-disk ≠ generated (`.:V6`)
V4: emitted pkl evals under vendored `pkl/Config.pkl`
V5: emitted nix parses & passes `nixfmt --check`
V6: ∀ emitted step bounded by a timeout (hk field if schema has one ?, else wrapper) — runaway guard, ⊥ perf budget
V7: whole-tree steps (`pkli check`, coverage) ⊥ glob-gated: a deletion | rename changes their verdict w/o touching a matching file
